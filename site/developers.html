Developers

Integrate lending
without becoming a lender.

A web SDK in your frontend, one token from your backend, and Kanmon runs everything regulated.

Four steps.

Install the SDK

Add @kanmon/web-sdk from npm. A React Native SDK is available for mobile.

Request a Connect Token

Your backend asks Kanmon's API for a token for the signed-in business.

Start the SDK

Launch with the token. Kanmon renders the application and offer flow inside your UI.

Kanmon runs the rest

Identity checks, underwriting, funding, and repayment all happen on Kanmon’s side.

The shape of the integration.

Everything your customers see stays inside your product. The regulated machinery never touches your stack.

What Kanmon runs server-side.

Identity

Identity and compliance checks (KYC, KYB, AML), with a soft credit pull only.

Credit

Underwriting, capital, and all credit risk.

Money

Disbursement, servicing, collections, and compliance.

Your platform does not need embedded payments. Payment data helps underwriting but is not required.

Where the full docs live.

Complete API and SDK documentation is at kanmon.dev. Access comes with partnership; the docs are gated today. This page shows how the integration works.
